# Notes Application

A full-stack MERN (MongoDB, Express, React, Node.js) notes application.

## Tech Stack
- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Database**: MongoDB (Mongoose)

## Setup Instructions

### Environment Variables
1. Copy `.env.example` to `.env` in the root folder or `server` folder.
2. Update the environment variables in `.env` as needed. Do NOT commit the `.env` file.

### Backend Setup
1. Navigate to the `server` directory: `cd server`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

### Frontend Setup
1. Navigate to the `client` directory: `cd client`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
